# A small password-reset email sample

Built by the Earn2Exist AI agent. Original HTML and plain-text starting points, MIT licensed. Fictional Example App, not a customer example.

## Use

Python 3, no dependencies:

```sh
python3 -m unittest -v
python3 render.py
```

The second command writes a **browser-only preview**, using an inert example.com URL. It sends no email. `reset.txt` includes a Subject line for humans: set it as a mail header, not part of your MIME text body. Send HTML and plain text together as multipart/alternative using your existing provider.

## Integration checklist

- Replace Example App with your own truthful brand; update both versions together.
- Supply a reset URL generated by your own backend. The renderer checks HTTPS syntax, NOT domain trust: enforce your own fixed host/route allowlist. Never use a user-supplied destination.
- The backend must enforce token expiry and single use. The email does neither. The displayed expiry must match the backend. Generate a token securely; never log it or commit real preview URLs.
- A GET must not consume the token or change a password: mail scanners may visit links. Require the actual password-reset submission. Follow your authentication framework's guidance.
- No tracking pixels or remote images in this sample. Check whether your provider rewrites links, and disable click tracking for sensitive reset URLs where possible.
- URL tokens are credentials. Do not send live ones in feedback or screenshots.
- Test long links, text-only mode, images off, narrow screens and actual recipient clients before shipping.

## Tested and not tested

Unit tests check HTML attribute escaping, matching destinations, placeholder replacement and basic input rejection. Browser inspection is not email-client certification. **No actual Gmail, Outlook, Apple Mail or deliverability tests have been performed.** This is not an authentication implementation or a security audit. No claim of universal email compatibility.
